# CMC · 15 años — Invitación interactiva

Sitio web estático de la invitación interactiva del aniversario de CMC.

## Archivos
- `index.html` — estructura de la invitación
- `styles.css` — estilos y animaciones
- `app.js` — interacción y lógica
- `config.js` — configuración editable del evento
- `.nojekyll` — compatibilidad con GitHub Pages

## Publicación en GitHub Pages
1. Crear un repositorio público en GitHub.
2. Subir estos archivos a la raíz del repositorio.
3. Ir a **Settings → Pages**.
4. En **Build and deployment**, seleccionar **Deploy from a branch**.
5. Seleccionar la rama `main` y carpeta `/ (root)`.
6. Guardar y esperar la publicación.

## Configuración
Editar `config.js` para cambiar fecha, horarios, lugares, mapas y futura integración de confirmación de asistencia.

> Esta versión no captura datos de invitados todavía. La captación se implementará después de la aprobación del prototipo.
